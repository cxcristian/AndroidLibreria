# RetoVentanas

App Android con Jetpack Compose y Material 3.

## Clonar

```bash
git clone https://github.com/cxcristian/AndroidLibreria.git
```

Abrir la carpeta en **Android Studio** → esperar que sincronicen las dependencias → **Run**.

## Hacer cambios y subir

```bash
git add -A
git commit -m "descripción del cambio"
git push
```

## Requisitos

- Android Studio Hedgehog (2023.1.1) o superior
- JDK 17+
- Gradle 9.1 (incluido)
